# Demo portraits

The 12 JPEGs in this folder are placeholder portraits for the demo dataset's
12 fictional employees (`madina.jpg`, `otabek.jpg`, etc. — filename matches
the member id in `src/data/demoData.ts`). **None of these depict a real
person.** They exist only so the portrait-focused card and profile layouts
can be previewed with a face instead of an initials placeholder.

## Source

Generated by [thispersondoesnotexist.com](https://thispersondoesnotexist.com/),
which serves a fresh StyleGAN2 (Karras et al., NVIDIA) output on every
request — a machine-learning model trained to synthesize photorealistic
faces that do not correspond to any real individual. Downloaded 2026‑09‑29.

## Rights

Because no real person is depicted, there is no individual whose likeness or
publicity rights are implicated. The site itself does not publish a formal
license grant (no LICENSE file or explicit terms of use), so treat these as
suitable for **this kind of internal, non-commercial demo/prototype use
only** — previewing a layout, not a shipped or monetized product. Do not
carry these specific files into a production build; swap in real,
Safia-approved staff photos (or a cleared commercial photo set) before this
project goes live. Each file was resized to 512×512 and re-compressed from
the ~600 KB original; no other edits were made.

## Selection

24 faces were generated and hand-reviewed; 12 were picked for a mix of
apparent age/gender and a plain, well-lit, forward-facing headshot (good for
cropping into a circle, a tall card portrait, and a wide profile hero
alike). Photos with a child's face or sunglasses obscuring the eyes were
excluded as unsuitable for an adult-staff context.
