# Demo portraits

The 12 JPEGs in this folder are placeholder headshots for the demo dataset's
12 fictional employees (`madina.jpg`, `otabek.jpg`, etc. — filename matches
the member id in `src/data/demoData.ts`). **None of these depict a real
Safia employee.** They exist so the portrait-focused card and profile
layouts can be previewed with a real face instead of an initials
placeholder.

## Same person as `public/fullbody/`

Each file here is a square crop **of the exact same source photograph** as
the matching file in `public/fullbody/` — nothing more than `sips --crop`
around the head and shoulders. This guarantees the small avatar and the
large full-length photo always show the same person: there is no separate
"headshot shoot" that could drift out of sync with the "full-body shoot,"
because there is only one shoot per person. See
`public/fullbody/README.md` for the source and license, which covers both
folders.

## Selection

Chosen for a natural, friendly expression, a clearly visible un-obscured
face, tidy work-appropriate clothing (aprons, chef whites, plain tops — no
visible competing brand names/logos), and a plain or uncluttered
background that reads as a real bakery/kitchen/food-service workplace, not
an athletic photo shoot or a fashion editorial. Candidates were rejected
for: a visible real business's logo or name on clothing/signage (several
strong photos were dropped for exactly this — including one literally
branded "Paris Baguette Boulangerie," a real chain), stylized/dramatic
fashion lighting that reads as an editorial rather than a workplace photo,
a face turned away or not visible, or more than one person in frame.
